# Copy, delete and export

- Select rows with a click, Ctrl or Cmd click, Shift click, or Ctrl or Cmd A.
- "Copy to right" and "Copy to left" list every file first: which ones are new and which ones are overwritten. Equal files are skipped. Modified times are kept.
- "Delete" asks which side, lists the files, and moves them to the Trash by default.
- "Export" saves the result as Markdown, CSV or HTML. With "Show equal files" off, only the differences are exported.
- "More > Sync folders" shows a full plan in a Markdown tab before it changes anything. Sync, the report of document changes and the three-way merge are Zovo Pro tools with 3 free tries each; a try counts only when the tool gives you a result.
- Leave files out: node_modules, .git and dist are left out by default, plus what .gitignore ignores. "More > Ignore rules" changes the list.
